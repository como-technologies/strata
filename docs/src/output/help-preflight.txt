$ strata preflight --help
Check that Palette can build a cluster, before the build

Usage: strata-preflight <SOURCE> [CHANGE] [OPTIONS]
       strata-preflight --watch cluster:UID [OPTIONS]
       strata-preflight --rules [OPTIONS]
       strata-preflight --promotion [OPTIONS]

Arguments:
  [SOURCE]  The body of a create as a file, or cluster:UID for a cluster as Palette holds it now
  [CHANGE]  A change of the cluster, as a file: the pools or the profiles that change

Options:
      --cloud <CLOUD>      The engine of a file: aws, eks, gcp, gke, azure, aks, maas, edge, vsphere; a cluster names its own
      --release <RELEASE>  The Palette release, such as 4.10; with none, a rule of one release applies; --promotion counts only the runs of this release
      --records <FILE>     Records of the profiles, as files or a pattern in quotes; with none, read from Palette
      --probes <FILE>      A file of custom probes, in the format of the rules; give it again for more
      --tier <TIER>        The tiers to run: static, palette, cloud, as a list; default all three
      --rule <ID>          Only these rules, by id; give it again for more; an id that is not in the catalog is an error
      --strict             Count a failed probe as a failed check
      --ready <PERCENT>    Exit 1 when the readiness is under this percentage, such as 80
      --offline            Read nothing from Palette: the static tier alone, from the files given
      --no-exec            Run no command of a cloud tool; each cloud rule is NOT CHECKED
      --watch              Watch the build of cluster:UID: the conditions and the events, until Running or a stuck state
      --every <SECONDS>    With --watch: seconds between two readings [default: 30]
      --limit <SECONDS>    With --watch: the longest watch, in seconds [default: 3600]
      --rules              List the rules, with the level and the tier of each, and run nothing
      --promotion          Compare the level of each rule with the runs of the ledger; exit 1 when they disagree
      --ledger <FILE>      A ledger of runs to read beside the one in the binary; give it again for more
      --schema <KIND>      Print the JSON Schema of a document, and run nothing [possible values: report, rules, ledger, promotion]
      --out <DIR>          Write report.md, report.json, report.html, world.json, and entity.json into this directory
      --format <FORMAT>    The report format: terminal, markdown, json, or html [default: terminal]
      --json               The same as --format json
      --compact            Write the JSON on one line
      --no-color           No color
      --color <WHEN>       When to color the report and the progress lines: auto (a terminal; NO_COLOR, CLICOLOR_FORCE, and TERM=dumb decide), always, or never [default: auto] [possible values: auto, always, never]
  -q, --quiet              No progress messages
  -v, --verbose            Print what each check ran: the request or the command, its answer, the time, and the verdict
  -h, --help               Print help
  -V, --version            Print version
