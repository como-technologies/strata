$ strata snapshot --help
Record a profile version, a cluster, an edge host, a cluster group, an app profile, or a pack version in a snapshot file, or each cluster of a tag: or filter: set in a directory

Usage: strata snapshot [OPTIONS] [REF]

Arguments:
  [REF]  What to record: a ref, or the source with --from-raw

Options:
  -o, --output <OUTPUT>
          Write to this file, not to standard output
      --raw-dir <RAW_DIR>
          Also save the raw API answers in this directory
      --from-raw <FROM_RAW>
          Read the raw answers of --raw-dir, with no network
      --from-candidate <FROM_CANDIDATE>
          Read a candidate file, before the version is in Palette
      --validate
          Ask Palette whether it takes the packs: of a candidate as a new profile, or of a profile version as an update of itself. A refusal exits 2 and writes no record
      --compact
          Write the JSON on one line
      --macros
          For a cluster: record the digest of the value Palette gives each macro the content uses
      --shape
          For a cluster: record the shape tier, the machine pools and the cloud part, with one more request
      --dir <DIR>
          For tag:KEY=VALUE or filter:NAME: write one record for each cluster into this directory, as <cluster name>.json
      --prune
          With --dir: remove each cluster record of the directory whose cluster the query no longer selects
      --format <FORMAT>
          With --dir: the report format: terminal, markdown, or json
      --json
          With --dir: the same as --format json
  -q, --quiet
          No progress messages
  -h, --help
          Print help
