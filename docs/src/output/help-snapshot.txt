$ strata snapshot --help
Record a profile version, a cluster, or a pack version in a snapshot file

Usage: strata snapshot [OPTIONS] [REF]

Arguments:
  [REF]  What to record: a ref, or the source with --from-raw

Options:
  -o, --output <OUTPUT>
          Write to this file, not to standard output
      --raw-dir <RAW_DIR>
          Also save the raw API answers in this directory
      --from-raw <FROM_RAW>
          Read the raw answers of --raw-dir, with no network
      --from-candidate <FROM_CANDIDATE>
          Read a candidate file, before the version is in Palette
      --compact
          Write the JSON on one line
      --macros
          For a cluster: record the digest of the value Palette gives each macro the content uses
      --shape
          For a cluster: record the shape tier, the machine pools and the cloud part, with one more request
  -q, --quiet
          No progress messages
  -h, --help
          Print help
