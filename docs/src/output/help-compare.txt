$ strata compare --help
Compare two profile versions, records, clusters, edge hosts, cluster groups, app profiles, or pack versions

Usage: strata compare [OPTIONS] <A> <B>

Arguments:
  <A>  The first side: a ref or a snapshot file
  <B>  The second side, in the same forms as the first

Options:
      --full             Also print the unified diffs of the values and the manifests
      --repave           Ask Palette if the change repaves the cluster side. One side must be a cluster. The other side is a profile version, or the update that waits for the cluster (cluster:<c>@pending)
      --validate         Ask Palette if it accepts the packs of the change on the cluster side; one side must be a cluster
      --format <FORMAT>  The report format: terminal, markdown, or json [default: terminal]
      --json             The same as --format json
      --color [<COLOR>]  Color the report: auto, always, or never [default: auto]
      --no-color         The same as --color=never
      --compact          Write the JSON on one line
  -q, --quiet            No progress messages, no note of an unknown value, and no warning of the send
  -h, --help             Print help
