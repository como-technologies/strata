$ strata candidate --help
Write a candidate file from a profile version or a record

Usage: strata candidate [OPTIONS] <REF>

Arguments:
  <REF>  A profile version, by ref or by record

Options:
  -o, --output <OUTPUT>        Write to this file, not to standard output
      --files-dir <FILES_DIR>  Write the values and the manifests to files in this directory
  -q, --quiet                  No progress messages
  -h, --help                   Print help
