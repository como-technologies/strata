$ strata list --help
List the profile versions, clusters, and projects in the scope

The first column of each line is a ref that the other commands accept. The scope is the configured project, or the project that --project or --project-name gives.

Usage: strata list [OPTIONS] [KINDS]...

Arguments:
  [KINDS]...
          What to list: profiles, clusters, projects. With none: profiles and clusters, or only profiles with --pack
          
          [possible values: profiles, clusters, projects]

Options:
      --project <PROJECT>
          List the profiles and clusters of the project with this uid, not of the configured project. '' is tenant scope. Strata always lists projects at tenant scope

      --project-name <PROJECT_NAME>
          The same as --project, with the project name

      --packs
          Also read each profile version for its type, consumers, and packs: one request for each

      --pack <TEXT>
          Keep the profile versions with a pack whose name contains TEXT, in upper or lower case. Sets --packs

      --format <FORMAT>
          The output format: terminal, markdown for a pull request comment, or json for a script
          
          [default: terminal]
          [possible values: terminal, markdown, json]

      --json
          The same as --format json

      --color [<COLOR>]
          When to color the terminal report. auto colors only a terminal, and obeys NO_COLOR and CLICOLOR_FORCE
          
          [default: auto]
          [possible values: auto, always, never]

      --no-color
          The same as --color=never

      --compact
          Write the JSON on one line

  -q, --quiet
          Do not write progress messages to standard error

  -h, --help
          Print help (see a summary with '-h')
