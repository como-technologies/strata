$ strata list --help
List the profile versions, clusters, and projects in the scope

Usage: strata list [OPTIONS] [KINDS]...

Arguments:
  [KINDS]...  What to list; with none, profiles and clusters [possible values: profiles, clusters, projects]

Options:
      --project <PROJECT>            List this project, by uid; '' is tenant scope
      --project-name <PROJECT_NAME>  The same, by project name
      --packs                        Also read each version for its packs and consumers
      --pack <TEXT>                  Keep the versions with a pack whose name holds TEXT; sets --packs
      --applied                      Also read each cluster for the profiles it applies
      --format <FORMAT>              The report format: terminal, markdown, or json [default: terminal]
      --json                         The same as --format json
      --color [<COLOR>]              Color the report: auto, always, or never [default: auto]
      --no-color                     The same as --color=never
      --compact                      Write the JSON on one line
  -q, --quiet                        No progress messages
  -h, --help                         Print help
