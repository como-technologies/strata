$ strata list --help
List the profile versions, clusters, projects, saved tag filters, and registries in the scope

Usage: strata list [OPTIONS] [KINDS]...

Arguments:
  [KINDS]...  What to list; with none, profiles and clusters [possible values: profiles, clusters, projects, filters, registries]

Options:
      --project <PROJECT>            Use this project, by uid; '' is tenant scope
      --project-name <PROJECT_NAME>  The same, by project name
      --detail                       Also read each version for its packs and their registries, its consumers, and whether it is published; read each cluster for the profiles it applies
      --pack <TEXT>                  Keep the versions with a pack whose name holds TEXT; reads each version as --detail does
      --tag <KEY=VALUE>              Keep the clusters with this label, KEY=VALUE or KEY; give it again for each label. Palette searches every project the key can read
      --filter <NAME>                Keep the clusters that a saved tag filter selects, by name or uid
      --cluster <TEXT>               Keep the clusters whose name or uid holds TEXT; reads each cluster as --detail does
      --format <FORMAT>              The report format: terminal, markdown, or json [default: terminal]
      --json                         The same as --format json
      --color [<COLOR>]              Color the report: auto, always, or never [default: auto]
      --no-color                     The same as --color=never
      --compact                      Write the JSON on one line
  -q, --quiet                        No progress messages, no note of an unknown value, and no warning of the send
  -h, --help                         Print help
