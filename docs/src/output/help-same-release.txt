$ strata same-release --help
Make sure that two or more records are one release

Strata compares each record with the next one, in the order given. A pair passes when the roots are equal. A pair also passes when the roots differ only by a tag name or by the uid that Palette gives a manifest pack, because the content is the same.

Exit status: 0 when each pair passes, 1 when a pair fails, 2 on an error.

Usage: strata same-release [OPTIONS] <RECORDS> <RECORDS>...

Arguments:
  <RECORDS> <RECORDS>...
          Two or more refs, in order: snapshot files, profile versions, or clusters

Options:
      --allow <ALLOW>
          Also pass a pair that differs only in this way

          Possible values:
          - registry-move: Packs from another registry, with the same tag, version, values, and manifests

      --format <FORMAT>
          The output format: terminal, markdown for a pull request comment, or json for a script
          
          [default: terminal]
          [possible values: terminal, markdown, json]

      --json
          The same as --format json

      --color [<COLOR>]
          When to color the terminal report. auto colors only a terminal, and obeys NO_COLOR and CLICOLOR_FORCE
          
          [default: auto]
          [possible values: auto, always, never]

      --no-color
          The same as --color=never

      --compact
          Write the JSON on one line

  -q, --quiet
          Do not write progress messages to standard error

  -h, --help
          Print help (see a summary with '-h')
