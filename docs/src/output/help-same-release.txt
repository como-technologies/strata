$ strata same-release --help
Make sure that two or more records are one release

Usage: strata same-release [OPTIONS] <RECORDS> <RECORDS>...

Arguments:
  <RECORDS> <RECORDS>...  Two or more refs, in promotion order

Options:
      --allow <ALLOW>
          Pass a pair that differs only in this way; give it more than one time for more [possible values: registry-move, no-digest, renumber]
      --project <PROJECT>
          Use this project, by uid; '' is tenant scope
      --project-name <PROJECT_NAME>
          The same, by project name
      --project-a <PROJECT_A>
          Read side A, the first ref, in this project, by uid; '' is tenant scope
      --project-name-a <PROJECT_NAME_A>
          The same, by project name
      --project-b <PROJECT_B>
          Read side B, the second ref, in this project, by uid; '' is tenant scope
      --project-name-b <PROJECT_NAME_B>
          The same, by project name
      --format <FORMAT>
          The report format: terminal, markdown, or json [default: terminal]
      --json
          The same as --format json
      --color [<COLOR>]
          Color the report: auto, always, or never [default: auto]
      --no-color
          The same as --color=never
      --compact
          Write the JSON on one line
  -q, --quiet
          No progress messages, no note of an unknown value, and no warning of the send
  -h, --help
          Print help
