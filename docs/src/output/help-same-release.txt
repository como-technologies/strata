$ strata same-release --help
Make sure that two or more records are one release

Usage: strata same-release [OPTIONS] <RECORDS> <RECORDS>...

Arguments:
  <RECORDS> <RECORDS>...  Two or more refs, in promotion order

Options:
      --allow <ALLOW>    Pass a pair that differs only in this way; give it more than one time for more [possible values: registry-move, no-digest]
      --format <FORMAT>  The report format: terminal, markdown, or json [default: terminal]
      --json             The same as --format json
      --color [<COLOR>]  Color the report: auto, always, or never [default: auto]
      --no-color         The same as --color=never
      --compact          Write the JSON on one line
  -q, --quiet            No progress messages
  -h, --help             Print help
