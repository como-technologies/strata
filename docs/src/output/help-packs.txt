$ strata packs --help
List the versions a registry offers for a pack

Usage: strata packs [OPTIONS] <NAME>

Arguments:
  <NAME>  The pack name, as the registry holds it

Options:
      --registry <NAME>  Only this registry, by name or uid
      --cloud <TYPE>     Keep the versions of this cloud, such as aws, and the versions of the cloud type all
      --latest           Only the newest version of each registry, and the version Palette calls the latest when it differs
      --format <FORMAT>  The report format: terminal, markdown, or json [default: terminal]
      --json             The same as --format json
      --color [<COLOR>]  Color the report: auto, always, or never [default: auto]
      --no-color         The same as --color=never
      --compact          Write the JSON on one line
  -q, --quiet            No progress messages
  -h, --help             Print help
