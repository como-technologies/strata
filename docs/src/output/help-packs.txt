$ strata packs --help
List the versions a registry offers for a pack

Reads the registries the key can see, and says which versions each one has, newest first, with the tags that point at each version. `pack:<name>@<version>` reads one of them.

Usage: strata packs [OPTIONS] <NAME>

Arguments:
  <NAME>
          The pack name, as the registry holds it

Options:
      --registry <NAME>
          Only this registry, by name or uid

      --cloud <TYPE>
          Keep the versions that support this cloud, such as aws or edge-native

      --latest
          Only the newest version of each registry

      --format <FORMAT>
          The output format: terminal, markdown for a pull request comment, or json for a script
          
          [default: terminal]
          [possible values: terminal, markdown, json]

      --json
          The same as --format json

      --color [<COLOR>]
          When to color the terminal report. auto colors only a terminal, and obeys NO_COLOR and CLICOLOR_FORCE
          
          [default: auto]
          [possible values: auto, always, never]

      --no-color
          The same as --color=never

      --compact
          Write the JSON on one line

  -q, --quiet
          Do not write progress messages to standard error

  -h, --help
          Print help (see a summary with '-h')
