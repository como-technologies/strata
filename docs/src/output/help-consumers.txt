$ strata consumers --help
List the clusters, edge hosts, cluster templates, and app deployments that use a profile version

Usage: strata consumers [OPTIONS] <REF>

Arguments:
  <REF>  A profile version or an app profile version, by ref or by record

Options:
      --list-only        Read the consumer list that Palette computes, and not each cluster of the fleet. Faster, but it does not find a consumer that the list omits
      --format <FORMAT>  The report format: terminal, markdown, or json [default: terminal]
      --json             The same as --format json
      --color [<COLOR>]  Color the report: auto, always, or never [default: auto]
      --no-color         The same as --color=never
      --compact          Write the JSON on one line
  -q, --quiet            No progress messages
  -h, --help             Print help
