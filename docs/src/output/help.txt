$ strata --help
Record, compare, and check Palette profile versions, the clusters and other objects that run them, and pack versions

Usage: strata <COMMAND>
       strata <A> <B>

Commands:
  behind        Report the pack versions that records pin, and the newer versions the registries offer
  candidate     Write a candidate file from a profile version or a record
  compare       Compare two profile versions, records, clusters, edge hosts, cluster groups, app profiles, or pack versions
  consumers     List the clusters and the edge hosts that use a profile version
  list          List the profile versions, clusters, projects, and saved tag filters in the scope
  packs         List the versions a registry offers for a pack
  preflight     Check that Palette can build a cluster, before the build; runs strata-preflight
  same-release  Make sure that two or more records are one release
  schema        Print the JSON Schema of a document or of the candidate file
  snapshot      Record a profile version, a cluster, an edge host, a cluster group, an app profile, or a pack version in a snapshot file, or each cluster of a tag: or filter: set in a directory
  verify        Make sure that each record agrees with Palette now
  help          Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Use "strata <command> --help" for more information about a command.
