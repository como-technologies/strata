$ strata verify --help
Make sure that each record agrees with Palette now

Usage: strata verify [OPTIONS] <SNAPSHOTS>...

Arguments:
  <SNAPSHOTS>...  Snapshot files; quote a pattern such as 'releases/**/*.json'

Options:
      --project <PROJECT>            Check the records in this project, by uid
      --project-name <PROJECT_NAME>  The same, by project name
      --summary                      One line for each record and a summary, also for one file
      --who                          For a record that drifted, read who changed it, and when, from the audit log of Palette
      --allow-no-digest              Accept a pack with no upstream digest: exit 0 and not 1, and still name it
      --format <FORMAT>              The report format: terminal, markdown, or json [default: terminal]
      --json                         The same as --format json
      --color [<COLOR>]              Color the report: auto, always, or never [default: auto]
      --no-color                     The same as --color=never
      --compact                      Write the JSON on one line
  -q, --quiet                        No progress messages
  -h, --help                         Print help
